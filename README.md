# ApplyFast AI

**ApplyFast AI** is an AI-powered Chrome extension designed to automate and speed up job applications and online form filling.

## Key Features
- **Smart Form Auto-Fill:** Automatically detects and fills repetitive job application fields in seconds.
- **AI-Assisted Responses:** Generates tailored answers for application questions based on your profile.
- **Multi-Portal Support:** Works smoothly across popular job boards and career portals.

## Current Status
Currently in **Beta Testing** with active feature improvements and subscription plans (Monthly & Yearly) rolling out soon.
